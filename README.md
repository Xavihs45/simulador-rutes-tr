# Simulador de Cerca de Rutes (Dijkstra, A* i A* Ponderat)

Programa desenvolupat en Python per al Treball de Recerca de 2n de Batxillerat (**Institut Miramar**). Permet comparar l'eficiència computacional i la precisió dels algorismes Dijkstra, A* clàssic i A* Ponderat (W=2) sobre la xarxa viària real de Viladecans i Gavà.

## Com executar el simulador

1. Descarrega els fitxers d'aquest repositori (**Code -> Download ZIP**) i descomprimeix-los en una mateixa carpeta.
2. Instal·la les llibreries necessàries des de la terminal:
   ```bash
   pip install osmnx networkx matplotlib numpy
   ```
3. Executa el programa:
   ```bash
   python "simulador_de_rutes web.py"
   ```
